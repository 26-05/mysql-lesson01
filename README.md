## 设计解释
- 主键为什么存在：唯一标识表中的每一行记录，保证数据的唯一性，且不能为空，方便精准定位和更新数据。
- 外键引用哪张表的哪一列：`books` 表的 `author_id` 引用了 `authors` 表的 `id` 列。
- 价格为什么选择这个类型：使用了 `DECIMAL(8,2)`。因为价格是金额，不能用浮点数，使用 DECIMAL 可以保证精确到小数点后两位，避免计算时出现精度丢失。

## 排错或边界验证
- 现象：执行 Q5 更新库存时，底部报错 `Error Code: 1175`。
- 原因：MySQL 默认开启了安全更新模式（Safe Update Mode），不允许使用非主键字段（如 title）直接更新数据。
- 处理与复验：我执行了 `SET SQL_SAFE_UPDATES = 0;` 关闭安全模式，并在更新语句中加上了 `AND stock > 0` 确保库存不会变成负数，重新执行后成功。
